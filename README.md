# AnomalyAnalyzer

## 概要
電脳的な世界観で、動くマップやグラフを表示し続けるWebページ。<br>(各数値に基づき、都市の超常現象発生を監視するシステム という設定)

マップのマーカー位置やグラフの数値・種類などはランダムに決まり変化していく。

## 主な使用技術
- React
- TypeScript
- Tailwind CSS
- Recharts
